# Medicinal Plants in Diabetic Nephropathy

This repository contains the publication data and manuscript for:
**Medicinal plants in diabetic nephropathy: bioactive compounds, mechanisms, and therapeutic potential**

**Authors:** Samia Akther, Fahmida Alam, Tahmeed Rezwan Shushmoy, Sumaiya Akter Annie, Md. Abeduzzaman Anon, Md. Shah Amran, Kamran Ul Baset, and Md. Josim Uddin
**Journal:** Frontiers in Immunology
**Published:** 12 November 2026
**DOI:** 10.3389/fimmu.2026.1964602

## Repository Structure
* `manuscript/`: Contains the review article text and section outlines.
* `data/`: Directory for storing extracted tabular data (e.g., medicinal plants, clinical trial findings).
* `src/`: Directory for computational scripts.
